Spec 03 // Computer Vision & Colorimetry

Automated Car Colour Detection (CarLens)

The Problem

Outdoor vehicle images suffer from glare, shadows, and shifting daylight, causing naive RGB color classifiers to misidentify car colors.

My Approach

Built an automated vehicle color detection algorithm using OpenCV color histograms (HSV space) paired with YOLOv8 vehicle bounding-box isolation and targeted data augmentation.

The Outcome

Achieved 98% accuracy across 1,000+ images under varying lighting conditions, with data augmentation improving lighting robustness by 15%.
